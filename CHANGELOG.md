# Versions

## 1.3.0

- `blindedPathToNode`: Add method to blind a path of nodes culminating in a
    destination

## 1.2.0

- `paymentPathFromChannels`: Add `receiver_base_fee_mtokens`,
    `receiver_fee_rate` to insert a synthetic fee taken by the receiver

## 1.1.0

- `paymentPathFromChannels`: Add method to blind a payment path with relay data

## 1.0.0

- `blindedPathFromHops`: Add method to blind a path of nodes to a destination
- `decryptBlindedPath`: Add method to decrypt blinded path data for a hop
- `onionForPath`: Add method to construct an onion message for a blinded path
